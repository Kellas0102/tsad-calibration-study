# Fixed-score calibration sensitivity in time-series anomaly detection

**Public release. Project-authored code is MIT licensed. The authors have authorized release of the included score-level materials; component-specific upstream terms and exclusions are documented below.**

This repository candidate recomputes comparisons from identified validation and test score arrays. It supports score-level reanalysis, not retraining the published detectors. It does not establish an equal-budget detector leaderboard.

## Included evaluation panels

- 354 legacy runs across twelve selected units and 30 adaptation runs on overlapping units: 384 primary records.
- Ten native-training TimesNet records, retained separately.
- Thirty source-model extension score records: ten split-disjoint TimesNet, ten corrected MEMTO, and ten retrained CATCH configurations.
- HAI evaluation-label overrides and timestamp-verified test1 sensitivity, SKAB reconstructed trial boundaries, and alarm-consolidation sensitivity results.

MEMTO rescoring is not new training. Multiple CATCH scoring RNGs are not independent training seeds. Model fitting, validation state and compute differ between extension groups; the accompanying manuscript records these differences.

## Install and run

Use a fresh virtual environment. Versions below match the current checked environment; compatibility with other versions needs testing.

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python code/reproduce_analysis.py
```

This command needs NumPy, Matplotlib and pypdf, but no torch, detector checkpoints, GPU, raw feature download or network access for analysis. On Windows use the corresponding virtual-environment activation command. Do not run the historical detector-training receipt scripts as analysis entry points.

Expected descriptive reversal counts in `results/margin_sensitivity.csv` are 87/180 for the four-policy legacy family and 44/180 at the post hoc 0.01 F1 margin. `results/policy_family_sensitivity.csv` reports 18/180 for the normal-only legacy family at that margin. The adaptation panel has one reversal in six comparisons at the same margin. These are selected-panel summaries, not independent site counts or population prevalence estimates.

## Optional paper build

Install a TeX distribution with `pdflatex` and `bibtex`, then run:

```sh
python code/build_paper.py
python code/validate_revision.py
```

The build searches `TEXBIN` (if set), the original Mac installation path, and then PATH. No margin or font-size changes are needed. PDF validation requires the documents to have been built; it is separate from numerical reproduction.

## Main files

- `inputs/manifest.json`: frozen primary run identities, score/metric paths and hashes.
- `evaluation_overrides/manifest.json`: separate evaluation corrections; original snapshots remain unchanged.
- `results/calibration_envelopes.csv`, `paired_contrasts.csv`: policy-specific pair results.
- `results/signed_channel_allocations.csv`: same-unit descriptive allocations.
- `results/hai_consolidation_summary.csv`, `policy_family_sensitivity.csv`: sensitivity summaries.
- `generated_tables/`: plain-text table renderings regenerated by numerical analysis for inspection; they are not manuscript source files.
- `received_heldout/` and `received_corrected/`: separate extension arrays and verification records.
- `protocol_validation/`: developer-created challenges and source-located public-case records, not independent reviewer validation.
- `vendor/affiliation-metrics-py/`: pinned reference implementation with its own license.
