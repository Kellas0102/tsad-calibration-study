# 2026-11-10 correction integration contract

This is a retrospective correction/sensitivity analysis after receiving the training-device evidence. The 2026-11-07 frozen snapshots, analyses, manuscripts and candidate ZIP remain unchanged. Code reuses the previously tested metric implementation; it never executes model code.

HAI: verify incoming loader-label vector against all thirty frozen HAI snapshots. Replace only evaluation labels, preserving scores and validation-calibrated thresholds. Report (a) corrected 60,000-point supplied timeline with test2 positional pairing assumption; (b) same corrected points with the known 54,000 file boundary enforced for event accounting; (c) timestamp-verified test1-only 54,000-point sensitivity. The latter is a sensitivity population, not a new independent unit. Recompute all four policies, tie-aware ranking, original-author affiliation, coverage identity, same-seed symmetric channel allocation, and the six existing offline consolidation widths. No width/policy is chosen by test performance. Continuous and boundary-aware quantities have different estimands and remain separate.

SKAB: verify exact length, contiguous offsets, trial row counts and anomaly counts using current official-reference files, and verify reconstructed labels against all legacy and recent frozen snapshots. Label agreement establishes consistency of this reconstruction, not uniqueness of historic file provenance. Report flattened stream, pooled within-trial one-to-one event confusion counts, and macro-trial results with defined-count denominators. Affiliation is macro over defined per-trial summaries, never an invented pooled probability. No-event conventions remain undefined as in the tested implementation. Trial-aware evaluation cannot undo cross-trial context in historical model scores.

TimesNet: preserve the ten returned runs as upstream-native-training diagnostics, not held-out validation benchmark evidence. Independently recompute >= and > archived-threshold metrics, tie-block calibration, normal-budget policy summaries and score provenance. No cross-model significance/superiority inference. Retain train/validation overlap caveat from the inspected upstream loader and runner.

The returned reports' event/affiliation proxies and their old-vs-corrected-label contrast are not substituted for the manuscript's metric implementation or policy-vs-policy contrast. Report label correction effects separately from calibration effects. Publication text will be updated only after revised tables are reconciled.
